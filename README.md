# ENC-DEC - Encryption/Decryption Tool

A web-based encryption/decryption tool for AES-256-CBC encryption, Base64 encoding, and URL encoding/decoding.

## Features

- 🔐 AES-256-CBC Encryption/Decryption
- 📝 Base64 Encode/Decode
- 🔗 URL Encode/Decode
- 🌐 Web-based interface
- ⚡ Fast and secure

## Requirements

- PHP 7.4 or higher
- OpenSSL extension enabled

## Local Setup

1. Clone the repository
2. Start PHP development server:
   ```bash
   php -S localhost:8000
   ```
3. Open `http://localhost:8000` in your browser

## Deployment

See `DEPLOYMENT_GUIDE.md` for detailed deployment instructions.

Quick deploy to Railway:
1. Connect this repository to Railway
2. Railway will auto-detect PHP and deploy
3. Your app will be live!

## Usage

1. Enter your text in the input field
2. Choose encryption/decryption or encoding/decoding option
3. Click the respective button
4. Copy the result
